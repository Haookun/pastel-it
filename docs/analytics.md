# 日志与隐私

Pastel it！不收集或上传用户使用信息。已移除 PostHog SDK、所有行为事件／会话计数、设备标识生成、统计开关和打包时凭据注入。旧版保存的统计偏好不会被读取，也不能恢复收集。历史版本已发送到第三方的数据不属于本地日志按钮的清理范围。

仅保留本机诊断日志：`~/Library/Logs/PastelIt/`。内容为时间与固定的启动／退出、存储失败、登录项失败等排障码，不记录复制内容、OCR、文件路径、搜索、按键、功能使用次数或错误正文；没有上传接口。日志最多14天，每个文件256 KiB，最多三个文件（768 KiB）。

“设置 → 隐私 → 本地诊断日志 → 删除过去日志”显示确认框，确认后仅删除 `diagnostic.log`、`diagnostic.1.log`、`diagnostic.2.log`，取消不清理。后续故障或重启仍可生成新日志。拒绝目录重定向、软链接、硬链接和非普通文件，不递归删除。

该按钮不删除偏好设置、快捷键、剪贴板历史、附件或macOS系统日志。历史与附件仍在 `~/Library/Application Support/PasteIt/`。macOS自行管理的系统日志／崩溃报告不能当成本应用文件日志清理；不使用全局日志清除命令。

独立合成验证使用临时日志目录；自动测试只清理临时夹具，不清理真实日志或配置。
