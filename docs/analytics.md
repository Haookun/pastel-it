# 日志与隐私

Pastel it！不收集或上传用户使用信息。已移除 PostHog SDK、所有行为事件／会话计数、设备标识生成、统计开关和打包时凭据注入。旧版保存的统计偏好不会被读取，也不能恢复收集。若某个历史版本曾发送数据到第三方，本地日志按钮也不会清理第三方数据；此处不推定历史版本实际发送过数据。

仅保留本机诊断日志：`~/Library/Logs/PastelItPublic/`。内容为时间与固定的启动／退出、存储失败、登录项失败等排障码，不记录复制内容、OCR、文件路径、搜索、按键、功能使用次数或错误正文；没有上传接口。写入日志时清理超过14天的文件，每个文件256 KiB，最多三个文件（768 KiB）；应用不运行或不写日志时，不另起后台任务清理。

“设置 → 隐私 → 本地诊断日志 → 删除过去日志”显示确认框，确认后仅删除 `diagnostic.log`、`diagnostic.1.log`、`diagnostic.2.log`，取消不清理。后续故障或重启仍可生成新日志。拒绝目录重定向、软链接、硬链接和非普通文件，不递归删除。

该按钮不删除偏好设置、快捷键、剪贴板历史、附件或macOS系统日志。历史与附件仍在 `~/Library/Application Support/PastelIt/`。macOS自行管理的系统日志／崩溃报告不能当成本应用文件日志清理；不使用全局日志清除命令。

独立合成验证使用临时日志目录；自动测试只清理临时夹具，不清理真实日志或配置。

## 联网与开发工具

无使用统计不代表禁止所有联网。链接预览可能请求对应网站、页面或图标，URL本身随该请求发送；点击修复语言资源时会请求GitHub，私有库的登录在浏览器进行，App不保存GitHub凭据。上游自动更新与MCP服务当前均停用。

OCR通过Apple Vision在设备上执行。Codex和Kimi用于开发，不是运行时OCR服务；应用没有向它们上传剪贴板的接口。

历史和附件是本机文件，未增加应用层内容加密；其访问保护依赖macOS账户与文件权限。忽略应用和受保护剪贴板类型过滤仍有效，但未标记的敏感纯文本不保证被识别为敏感内容。

项目测试和文档截图使用合成内容；不要上传真实数据库、附件或用户日志来展示功能。
