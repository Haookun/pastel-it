## 以后参考的方式

维护者提供的截图展示了“系统设置 → 隐私与安全性”中的“已阻止……以保护 Mac”和“仍要打开”。后续暂参考 **ad-hoc 签名、未公证应用，由用户对单个应用确认打开** 的方式；不把 Developer ID 或公证当作前置要求。

这是 macOS Gatekeeper 的安全检查提示，并非开源软件专属。提示是否出现、具体文案及能否继续，与签名、公证、下载来源和系统策略有关；不能把出现该按钮写成“Apple 已审核通过”或保证每台 Mac 都相同。

如果未来用户确认应用来源可信、文件未被改动，Apple 官方流程是：先尝试打开，再到“系统设置 → 隐私与安全性”点击该应用的“仍要打开”，按后续提示确认。该例外针对单个应用。参考 [Apple：在 Mac 上安全地打开 App](https://support.apple.com/zh-cn/102445)（2026-10-29核对）。

不以关闭 Gatekeeper／SIP、全局允许任意来源或清除隔离标记的脚本作为标准打开步骤。若系统提示文件损坏、已知恶意内容或其他不能继续的情况，不将其混同为普通未公证提示。
