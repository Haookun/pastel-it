# Pastel it！功能说明

## 历史记录与粘贴

应用在菜单栏运行，采集文字、富文本、链接、图片和文件引用。支持搜索、类型筛选、固定与文件夹。保留暂停采集、忽略应用和受保护剪贴板类型过滤。应用自己写入的剪贴板会通知监听器抑制重复采集。

“写入系统剪贴板”不需要辅助功能权限；“向目标应用自动粘贴”需要。没有权限时仍能准备内容并由用户手动按 ⌘V，不会擅自修改系统授权。

## OCR 与表格

“设置 → OCR”提供以下识别参数；快捷粘贴在独立栏目：

| 参数 | 行为 |
| --- | --- |
| OCR 开关 | 关闭后停止新识别，保留既有结果；正在执行但设置已变化的旧结果不会写回 |
| 自动语言 | 交给系统 Vision 选择语言；也可切换为指定语言集合 |
| 指定语言 | 简体中文、繁体中文、英文、日文、韩文、法文、德文、西班牙文 |
| 表格识别 | macOS 26+ 检测表格并输出 Markdown；关闭或检测失败时保留文字 OCR |
| 精确/快速 | 优先精度或速度；快速模式不支持指定语言时使用精确模式 |
| 语言纠错 | 使用系统语言纠错，默认关闭 |
| 最小文字高度 | 图片高度的 0%～10%；0% 不主动过滤小字 |

图片识别在后台执行，串行安排系统识别任务。普通文字和表格都不依赖云 OCR 服务。现有图片点击 Re-run 才应用新设置，不会批量改写历史。自动语言检测仍可能漏掉英文句子中的少量中文，小字、旋转、复杂合并表格与模糊截图需要人工校正。

表格首行成为 Markdown 表头，空单元格保持位置。合并单元格文字仅写在左上角，不保留视觉合并。表格前后文字保留；`|`、换行等内容转义，避免意外增列。当前输出是 Markdown 文本，没有增加 Excel 或 HTML 剪贴板格式。

## 横向浏览与复制时间轴

卡片区域的纵向鼠标滚轮转换为横向移动。原生横向手势继续交给系统处理；嵌套文字区域的纵向滚动保留。

底部时间轴左新右旧，按当前筛选结果中的原始复制时间计算位置。悬停会放大附近刻度并显示时间；点击或拖动会选中并滚动到最接近该时间的记录，随后可查看卡片文本或按 Space 预览。固定与使用后前置不会改变原始复制时间。

原模型只保存每条记录的首次复制时间、最后使用时间与复制次数；本版没有增加每次重复复制的事件日志，因此时间轴不能重建同一内容的全部重复复制时刻。

## 快捷粘贴

设置位于独立“快捷粘贴”栏目，默认关闭。它读取的是**当前系统剪贴板**，不是历史第一条或筛选后的第一条。转换范围可多选：

- 文字 → 去除富文本格式后的纯文本。
- 图片 → 按 OCR 栏目设置识别，关闭 OCR 时不转换图片。
- 文件 → 文件名，多文件以换行分隔，不输出完整本地路径。

与打开历史分别配置快捷键：历史默认 ⇧⌘C，快捷粘贴默认 ⇧⌘V。自定义组合冲突时拒绝覆盖并提示修改。清空快捷粘贴快捷键会同时关闭该功能，恢复全部默认快捷键也会关闭它。

识别期间如果系统剪贴板或目标应用发生变化，会取消转换后的写入。自动粘贴后恢复原剪贴板；如果用户期间复制了新内容，则保留新内容。没有辅助功能权限时，准备纯文本并提示手动 ⌘V。

## 本地化、数据与更新

包含九种界面语言资源，缺译项可回退英文。资源缺失或损坏时，尝试校验后的匹配缓存，再使用代码内置英文继续启动并提示修复。“设置 → 关于 → 语言资源”可下载或导入语言包；私有仓库需浏览器登录后下载导入，公开仓库可直接下载。校验版本和 SHA-256 后只安装语言缓存，配置、历史与 App 签名保持不变。这不是 OCR 模型下载。见 [语言恢复](language-recovery.md)。

v0.3.0 起使用独立标识 `io.github.haookun.pastel-it` 及全新 `~/Library/Application Support/PastelIt/`，不迁移原版历史。内部 Swift 目标名保持不变。本派生版尚未配置自己的更新源，已移除上游更新地址和公钥，并停用 Sparkle 启动。

## 精简后的功能边界

仅保留“打开剪贴板”和“快捷粘贴”两个全局操作。旧的独立“粘贴为纯文本”、⌃⌘V、⇧Return 纯文本粘贴及“默认纯文本粘贴”设置移除；单条历史记录的“复制为纯文本”保留为复制操作。

旧版完整默认快捷键迁移为 ⇧⌘C/⇧⌘V；自定义或已清空的键保留。快捷键序列化升级到 schema 2，不再写入已移除操作的绑定。

Paste Stack 源码归档，不创建控制器、收集队列、显示面板或拦截 ⌘V。MCP 源码归档，没有开关或 URL 复制入口，生产运行不初始化服务；旧的 agentAPIEnabled=true 会迁移为 false，归档服务器的启动方法也有关闭保护。保留协议测试不代表产品在运行服务。

界面调整及实际系统接口见 [原生界面与系统能力](native-ui-and-architecture.md)。

## 时间轴与候选栏

在设置 → 剪贴板 → 显示样式中选择；默认保留时间轴，修改后持久化。⇧⌘C 打开所选样式，不新增第三个全局快捷键。

候选栏按现有最近使用排序显示历史（排除已从时间线移除的项），不继承时间轴搜索或文件夹筛选。使用原生纵向列表，每页最多 10 项，1–9／0 或鼠标点选；Tab 下一页、Shift-Tab 上一页，到首尾停止。上下键浏览当前页，左右键翻页，Return 确认，Escape 关闭。数字键只在本工具候选面板及其预览子窗口内处理，不抢占 Command／Control／Option 组合。

图片显示类型图标与已有 OCR 摘要，未识别时显示图片类型；文件显示文件名，多文件显示额外数量。悬停查看图片、完整路径或长文本。选择条目仍写入原内容类型，并遵循原来的复制／直接粘贴设置；需要图片转文字或文件转文件名时，使用独立的快捷粘贴功能。无辅助功能权限时保留可手动 ⌘V 的复制路径。

两种展示复用同一个 AppKit 面板、PasteController 和自身写入抑制链路，不改变存储目录或清空历史。

候选栏在打开前读取目标应用的插入位置，显示在该行下方，空间不足时翻到上方；横向和纵向均限制在对应显示器可见区域内。翻页复用同一位置基准，避免跳回屏幕底部。无辅助功能权限、密码框或目标应用不提供范围坐标时，回退到打开时的鼠标附近，提示收在信息图标的悬停说明中，不读取选中文本或输入框正文。时间轴仍位于屏幕底部。

设置的“应用”组包括通用、剪贴板、OCR、快捷粘贴；“数据”组包括文件夹、隐私、存储，另有关于页。剪贴板显示样式下有无数据依赖的矢量动画预览，尊重系统减少动态效果。候选样式下提供辅助功能权限状态及获取权限按钮，由用户点击后进入系统授权流程；回到应用时刷新状态。

候选行仅显示第一行；还有后续行时追加省略号，首行超过可用宽度时由原生控件尾部省略。文本、OCR表格和文件名共用该展示规则，固定行高内不换行、不覆盖相邻项；历史原文、悬停全文和复制内容保持完整。

## 数据、日志与联网

不收集或上传使用统计，PostHog 依赖与事件代码已移除。仅保留本机固定诊断码日志；“设置 → 隐私 → 删除过去日志”带确认且不删除配置、历史和附件。

链接预览可能请求链接或图标，语言资源修复由用户点击后访问GitHub。OCR仍在设备上执行，无统计不等于整个应用不联网。见 [隐私与日志](analytics.md)。

v0.3.0 提供 Apple Silicon ad-hoc 签名 DMG，无 Apple 公证，自动更新关闭。见 [分发约定](distribution.md)。
