# Pastel it！功能说明

## 历史记录与粘贴

应用在菜单栏运行，采集文字、富文本、链接、图片和文件引用。支持搜索、类型筛选、固定、文件夹与 Paste Stack。保留暂停采集、忽略应用和受保护剪贴板类型过滤。应用自己写入的剪贴板会通知监听器抑制重复采集。

“写入系统剪贴板”不需要辅助功能权限；“向目标应用自动粘贴”需要。没有权限时仍能准备内容并由用户手动按 ⌘V，不会擅自修改系统授权。

## OCR 与表格

设置 → OCR 与快捷粘贴提供：

| 参数 | 行为 |
| --- | --- |
| OCR 开关 | 关闭后停止新识别，保留既有结果；正在执行但设置已变化的旧结果不会写回 |
| 自动语言 | 交给系统 Vision 选择语言；也可切换为指定语言集合 |
| 指定语言 | 简体中文、繁体中文、英文、日文、韩文、法文、德文、西班牙文 |
| 表格识别 | macOS 26+ 检测表格并输出 Markdown；关闭或检测失败时保留文字 OCR |
| 精确/快速 | 优先精度或速度；快速模式不支持指定语言时使用精确模式 |
| 语言纠错 | 使用系统语言纠错，默认关闭 |
| 最小文字高度 | 图片高度的 0%～10%；0% 不主动过滤小字 |

图片识别在后台执行，串行安排系统识别任务。普通文字和表格都不依赖云 OCR 服务。现有图片点击 Re-run 才应用新设置，不会批量改写历史。自动语言检测仍可能漏掉英文句子中的少量中文，小字、旋转、复杂合并表格与模糊截图需要人工校正。

表格首行成为 Markdown 表头，空单元格保持位置。合并单元格文字仅写在左上角，不保留视觉合并。表格前后文字保留；`|`、换行等内容转义，避免意外增列。当前输出是 Markdown 文本，没有增加 Excel 或 HTML 剪贴板格式。

## 横向浏览与复制时间轴

卡片区域的纵向鼠标滚轮转换为横向移动。原生横向手势继续交给系统处理；嵌套文字区域的纵向滚动保留。

底部时间轴左新右旧，按当前筛选结果中的原始复制时间计算位置。悬停会放大附近刻度并显示时间；点击或拖动会选中并滚动到最接近该时间的记录，随后可查看卡片文本或按 Space 预览。固定与使用后前置不会改变原始复制时间。

原模型只保存每条记录的首次复制时间、最后使用时间与复制次数；本版没有增加每次重复复制的事件日志，因此时间轴不能重建同一内容的全部重复复制时刻。

## 快捷粘贴

设置在 OCR 页面下方，默认关闭。它读取的是**当前系统剪贴板**，不是历史第一条或筛选后的第一条。转换范围可多选：

- 文字 → 去除富文本格式后的纯文本。
- 图片 → 按上方 OCR 设置识别，关闭 OCR 时不转换图片。
- 文件 → 文件名，多文件以换行分隔，不输出完整本地路径。

与打开历史分别配置快捷键。首次开启尝试 ⇧⌘V；该组合默认也用于打开历史，冲突时拒绝覆盖并提示先修改其中一个。清空快捷粘贴快捷键会同时关闭该功能，恢复全部默认快捷键也会关闭它。

识别期间如果系统剪贴板或目标应用发生变化，会取消转换后的写入。自动粘贴后恢复原剪贴板；如果用户期间复制了新内容，则保留新内容。没有辅助功能权限时，准备纯文本并提示手动 ⌘V。

## 本地化、数据与更新

界面沿用已有九种语言资源；本轮新增功能提供英文和简体中文，其余未翻译文案使用英文回退。设置、窗口缩放、快捷键录入与授权后重启提示沿用本机修复。

原有 bundle ID、内部 Swift 目标名和 `~/Library/Application Support/PasteIt/` 保持不变，以兼容已有历史与权限身份。Pastel it！应替代原安装，不能同时作为独立应用运行。私人派生版尚未配置自己的签名更新源，已移除上游更新地址和公钥，并停用 Sparkle 启动。
