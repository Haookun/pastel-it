# 开始使用 Pastel it！

[返回首页](../README.md) · [功能细节](features.md) · [隐私说明](analytics.md)

## 获取和运行

2026-10-29 约定：当前仅记录这些步骤，不执行构建、安装或对外打包。后续分发方式见 [分发约定](distribution.md)。

当前没有正式二进制 Release，也没有自动更新渠道。请从仓库源码构建；私有仓库需要先取得访问权限。最低部署目标为 macOS 14，构建需要 Swift 6.2+、相应 Xcode／Command Line Tools 和 Python 3。当前实际验收范围见 [开发指南](development.md)。

```sh
git clone https://github.com/Haookun/pastel-it.git
cd pastel-it
swift test --scratch-path /private/tmp/pastel-it-build
PASTEIT_BUILD_PATH=/private/tmp/pastel-it-build \
  ./scripts/package-release.sh --variant arm64 --local-test
```

构建输出 `dist/local-test/arm64/Pastel it！.app` 及干净的签名压缩包。同目录的“开始普通验证.command”会解压到系统临时目录并启动，使用真实历史；确认后可将 App 安装到 Applications。脚本本身不自动安装。

“开始合成验证.command”使用独立偏好、内存历史和合成记录，退出不保存这些示例。它仍会响应系统剪贴板与快捷键，适合复制测试文字；不要把合成模式下的退出清空当成持久化故障。工程内部的 `--ui-review` 是另一条显式隔离检查路径，不监听真实系统剪贴板。

本机构建使用 ad-hoc 临时签名，无需申请 Developer ID。它不等于 Apple 公证；如果下载后被 macOS 拦截，请采用 [Apple 的单个应用允许打开流程](https://support.apple.com/en-us/102445)。完整打包说明见 [mac-packaging.md](mac-packaging.md)。

## 第一次使用

1. 启动后在菜单栏找到蛋挞图标，复制一段测试文字或图片。
2. 按 `⇧⌘C` 打开历史。也可通过菜单栏入口打开。
3. 在“设置 → 剪贴板 → 显示样式”选择时间轴或候选栏，默认候选栏。
4. 时间轴可用鼠标滚轮横向浏览，底部刻度定位复制时间；候选列表每页最多十项，按 `1`–`9`、`0` 选取，`Tab` 下一页、`Shift-Tab` 上一页。
5. 在“设置 → OCR”调整识别参数；需要当前剪贴板的纯文本转换时，再开启独立“快捷粘贴”栏目。

候选行只展示首行，隐藏后续内容时显示省略号；鼠标悬停可看预览。展示省略不截断实际保存或复制的内容。

## 快捷粘贴

默认快捷键为 `⇧⌘V`，功能默认关闭。它转换的是**当前系统剪贴板**，不是历史第一条。

| 勾选范围 | 结果 |
| --- | --- |
| 文字 | 去掉富文本格式 |
| 图片 | 按 OCR 页设置识别为文字／Markdown 表格；OCR 关闭时不转换图片 |
| 文件 | 提取文件名，多项用换行分隔 |

两组全局快捷键可分别修改或清空，冲突会被提示。自动粘贴前会检查目标应用与剪贴板是否变化；新复制内容不会被旧转换结果覆盖。没有辅助功能权限时，可准备内容后手动按 `⌘V`。

## 权限

| 能力 | 是否需要辅助功能权限 |
| --- | --- |
| 读取剪贴板、保存历史、OCR、复制条目 | 不需要 |
| 自动向目标应用粘贴 | 需要 |
| 在其他应用的文字光标附近定位候选列表 | 需要目标应用提供可读的光标几何信息 |

“设置 → 剪贴板”选择候选栏后可查看权限状态并点击获取权限；直接粘贴也有对应入口。授权后回到应用检查状态，必要时重新打开应用。取不到光标位置时，候选列表会在鼠标附近显示；不因此读取输入框正文。

## 历史、升级和清理

- 历史、图片附件、缩略图及修复语言资源：`~/Library/Application Support/PastelIt/`。
- 配置：macOS 偏好域 `io.github.haookun.pastel-it`。
- 本机诊断日志：`~/Library/Logs/PastelItPublic/`。

本派生版沿用上游身份和存储目录。升级前备份已有数据，退出原版后替换 App；不要同时运行原版与本版。文件条目保存的是文件引用，不等同于给原文件做备份。

“设置 → 隐私 → 删除过去日志”只清理本应用日志；“删除历史”是另一项操作，不要混淆。暂停采集、忽略应用和敏感剪贴板标记过滤仍可使用；未被应用标记的敏感纯文本不会自动变成不可记录的内容。

## 常见问题

| 现象 | 说明或处理 |
| --- | --- |
| 候选列表出现在鼠标旁 | 辅助功能未授权，或目标应用不提供光标范围；这是预设回退 |
| 已复制但没有自动粘贴 | 查看权限与复制／直接粘贴设置，先尝试手动 `⌘V` |
| 没有表格输出 | 表格识别需要 macOS 26+ 和开关启用；识别不到时保留普通文字 |
| 英文中少量中文漏识别 | 系统 Vision 的已知限制之一；可尝试指定语言与精确模式，仍需人工核对 |
| 关闭 OCR 后旧结果仍在 | 开关控制新任务；旧图可用 Re-run 按当前设置重新识别 |
| 提示语言资源缺失 | 可先用英文继续；在“设置 → 关于 → 语言资源”下载或导入匹配包，详见[恢复说明](language-recovery.md) |
| 私有仓库下载提示登录 | 在浏览器登录 GitHub 后下载，再用“安装已下载语言包”导入；App 不保存 GitHub 凭据 |
| 整个 App 被系统判断为损坏 | 系统可能在代码运行前拒绝签名；语言资源修复不能替代重新安装完整 App |
| 测试包报告 Finder/resource fork 错误 | 按构建命令使用非同步临时目录；不要为通过测试删除真实历史或重置权限 |

反馈问题时请给出系统版本、芯片、操作步骤和预期／实际结果。截图或日志只用合成内容；不要提交剪贴板数据库、附件或登录凭据。[贡献指南](../CONTRIBUTING.md)
