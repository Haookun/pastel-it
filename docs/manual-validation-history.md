# Pastel it！手动确认清单

由用户逐项确认实际功能，agent 负责代码检查、自动测试、编译、记录反馈和修复。
2026-10-20 用户已明确反馈“功能没有问题”，据此接受当前版本并授权安装。下表记录为“用户总体确认”；用户没有逐项提供执行明细，不将其扩写为每个权限分支均已单独测试。

反馈格式：`01 通过`、`02 有问题：操作……，实际……，预期……` 或 `03 未测`。
每次确认一项或一小组即可。修复后的项目标为“待复测”，用户确认后才改为“通过”。

## 开始前

- 先退出正在运行的旧版 Paste It，避免相同 bundle ID 和快捷键同时占用；安装前测试不替换现有应用；2026-10-20 用户另行授权将新版安装到 `/Applications/Pastel it！.app`。
- 本机 App：`dist/local-test/arm64/Pastel it！.app`，使用无需账号/证书的 ad-hoc 签名。
- 第一轮建议使用合成验证：双击本机产物目录中的 `开始合成验证.command`，或在仓库根目录执行：

  ```sh
  "dist/local-test/arm64/开始合成验证.command"
  ```

- 合成模式自带 48 条记录，使用独立偏好和临时历史，退出后清理；不用于验证重启持久化。仍会使用系统剪贴板，只复制无隐私的测试文字、图片和文件。
- 启动器从干净签名压缩包解压到系统临时目录、校验后运行，避免项目所在文件同步目录反复附加 Finder 元数据导致校验失败；不安装应用或改变系统安全设置。
- 第 18 项持久化验证需退出合成模式，双击 `开始普通验证.command`，以普通模式使用已有真实历史。不要删除原历史、重置权限或关闭系统保护来使测试通过。
